# Hi, I'm Pedro

I build practical, local-first tools for **secure AI agents and integrations**.

I focus on the questions that matter when an agent gets real tools: what did it attempt, what changed, and was it allowed to do so?

## Projects

### [ScopeLens](https://github.com/pedronavarro-labs/scopelens)
**Your agent needs to read code. Why can it write?**

A local permission review for GitHub Apps and MCP configurations. It compares a task with granted scope, explains evidence gaps, and produces a shareable report without changing permissions or starting MCP servers.

- Start with the synthetic [before/after demo](https://github.com/pedronavarro-labs/scopelens/tree/main/demo).
- Looking for early feedback from security engineers, platform teams and agent builders.

### [AgentReplay](https://github.com/pedronavarro-labs/agentreplay)
A local laboratory for testing tool-using agents after integration failures: uncertain writes, duplicate actions, rate limits and permission denials.

- Reproduce a failure with deterministic fixtures.
- Inspect action traces and assert on the real resulting state.
- Connect an agent through Python or a local MCP server.

## How I work

Small reproducible examples, explicit limitations and tests that check outcomes.

If you have a synthetic failure case or feedback about agent permissions, open an issue in either project.

## Building: AgentReplay

[AgentReplay](https://github.com/pedronavarro-labs/agentreplay) is a local laboratory for testing tool-using agents against integration failures.

- Reproduce uncertain writes, duplicate actions and permission failures.
- Inspect tool calls and verify the resulting state.
- Connect an agent through Python or a local MCP server.

**Current stage:** development alpha. The offline demo uses scripted reference policies. Evaluation with real AI agents is the next milestone.

## How I work

Small reproducible examples, explicit limitations and tests that check outcomes.

I'm interested in contributions around integration reliability, agent evaluation and secure automation. If you have a reproducible failure case, open an issue in AgentReplay using synthetic data.
